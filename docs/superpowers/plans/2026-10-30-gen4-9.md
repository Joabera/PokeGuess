# PokeGuess Gen 4–9 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Grow the ConvNeXt main model from 386 to 1025 classes (Gen 1–9), gate it on agreed accuracy bars, and ship it to Upload and Live on Azure — keeping the ResNet-18 Gen 1 specialist untouched.

**Architecture:** A pure `classlist.py` defines names (first 386 frozen, new ones from PokéAPI species, `safe_name` everywhere). The existing scraper builds data for #387–1025 next to a copy of the Gen 1–3 dataset; `train.py` runs the two warm-started phases; a new `gate.py` decides PASS/FAIL; `export_onnx.py` writes `convnext_gen1-9*.onnx`. Inference, web, Live and deploy switch to the new files and the `gen1-9` label.

**Tech Stack:** Python 3.13 (old repo CUDA venv: torch 2.6.0+cu124, OpenCLIP, imagehash), PyTorch/torchvision, ONNX Runtime, Flask, ASP.NET Core .NET 10, xUnit, GitHub Actions, Azure.

**Spec:** `docs/superpowers/specs/2026-10-30-gen4-9-design.md`

## Review Focus

1. **Stale card cache**: running `cards` without `--refresh-cards` silently gives Gen 4–9 zero card art. `data_report.py` must exit 1 when any class in the class file has no folder or zero images. Test in Task 2.
2. **Model ↔ class-file mismatch**: if ImageFolder's class set differs from `class_names_v2.txt` (e.g. an unsafe folder name slipped in), the app would show wrong labels. Export must fail unless `set(best_sketch_v3_classes) == set(class_names_v2)` and the count is 1025. Test in Task 5.
3. **Generation boundary off-by-one** (#151/#152, #386/#387, #905/#906, #1025): Stats would misfile Pokémon. Test both sides of every boundary in Task 7.
4. **Browsers holding the v2 Live model** with v3 class names → wrong labels. `MODEL_VERSION` bump + URL rename; Task 7 test asserts `live.js` references `convnext_gen1-9.onnx` and `v3`, and no `gen1-3` file.
5. **Old guesses after the switch**: Stats rows with `gen1-3` must still render and be labeled "(previous)". Test in Task 7.
