# PokeGuess Gen 4–9 — Design

**Date:** 2026-10-30
**Branch:** `feat/gen4-9`
**Status:** Approved in brainstorming, pending spec review
**Builds on:** the Gen 1–3 training handoff (pre-rebuild), the .NET rebuild and Live mode specs

## Goal

Extend recognition from the 386 Pokémon of Gen 1–3 to **all 1025 (Gen 1–9)**, for both Upload and Live, and ship it on the current Azure site.

**Decisions (from brainstorming)**

- All of Gen 4–9 in one go.
- The **ResNet-18 Gen 1 specialist is never retrained or removed**. Its file (`fine_tuned_with_pencil_sketch.pth` / `resnet18_gen1.onnx`) and its routing stay exactly as they are.
- The ConvNeXt main model grows to 1025 classes, warm-started from the current model (`models/best_sketch.pth`). It still covers Gen 1 so it can route to the specialist.
- A numeric **ship gate** is agreed before training (below). If the gate fails, stop and review; nothing ships.

**Success criteria**

- Gate passes on the held-out test split.
- Upload and Live recognize Gen 4–9 Pokémon on the live site; Gen 1 images still route to the specialist.
- Existing data (guesses, Stats) keeps working; history stays truthful about which model answered.

**Out of scope**

- Retraining or replacing the Gen 1 specialist.
- Regional/alternate forms as separate classes (TCG and sprite forms bucket into the base Pokémon).
- Search-engine scraping (the `scrape` stage stays unused).
- The Hugging Face deploy described in the handoff (superseded by Azure).

## Class list

`training/build_class_list.py --max-id 1025` writes `models/class_names_v2.txt` (National Dex order, one per line) and `models/pokeapi_slugs.json` (`{name: slug}`).

- **#1–386 keep their exact current names** (read from the existing `class_names_v2.txt`), e.g. `Nidoran-F`, `Mr. Mime`, `Farfetch'd`, `Deoxys`. Existing DB rows, the specialist's `LEGACY_FIX` targets, and Stats keep matching.
- **#387–1025**: name = English entry of `names[]` from `https://pokeapi.co/api/v2/pokemon-species/{id}`; slug = `name` of `https://pokeapi.co/api/v2/pokemon/{id}` (e.g. `Giratina` → `giratina-altered`).
- `safe_name(name)`: the single function that makes a name usable as a Windows folder and ImageFolder label. Removes `:` (and any of `<>:"/\|?*`), collapses repeated spaces, strips trailing dots and spaces. Examples: `Type: Null` → `Type Null`, `Mime Jr.` → `Mime Jr`. Applied to every name **before** writing the class file, so the class file, folders, model outputs, DB, Pokédex and pages share one string.
- Validation (fails the build): 1025 names; first 386 identical to the current list; all unique (case-insensitive); all `safe_name(n) == n`; all ≤ 40 characters (DB column); every name has a slug.

## Training

- **Phase 1 (color):** `train.py --data-dir data/raw --epochs 14 --lr 1.5e-4 --init-weights models/best_sketch.pth --out models/best_color_v3.pth --out-dir runs/color_gen1-9`.
- **Phase 2 (sketch):** `train.py --data-dir data/raw --epochs 10 --sketch --init-weights models/best_color_v3.pth --lr 5e-5 --out models/best_sketch_v3.pth --out-dir runs/sketch_gen1-9`.
- Existing checkpoints (`best_sketch.pth`, `best_color.pth`, `fine_tuned_with_pencil_sketch.pth`) are never overwritten.
- Training settings unchanged from the handoff (224 px, augmentations, stratified 80/10/10 seed 42, WeightedRandomSampler, AdamW wd 0.05, cosine LR, label smoothing 0.1, AMP, early stop patience 6). `--init-weights` loads shape-matching tensors only, so the 1025-class head starts fresh.
- `train.py` writes `models/best_sketch_v3_classes.txt` (ImageFolder order); it becomes `models/best_sketch_classes.txt` at export time.

## Ship gate

`training/gate.py` (new) loads the phase-2 checkpoint and evaluates it on the **test split** (same stratified split, seed 42, as `train.py`) in two modes: clean (eval transform) and sketch (pencil sketch, p = 1.0, as `train.py` evaluates phase 2).

| Check | Bar |
|---|---|
| Clean top-1, all classes | ≥ 95.0% |
| Sketch top-1, all classes | ≥ 90.0% |
| Clean top-1, Gen 1–3 subset (dex #1–386) | ≥ 95.7% |
| Sketch top-1, Gen 1–3 subset | ≥ 92.8% |

Output: each metric vs bar, overall `PASS`/`FAIL` (exit code 0/1), the 20 worst classes (clean), classes with < 10 images, and the **live-mode confidence check**: share of correct clean test predictions with confidence ≥ 80% (current Live search threshold), plus the 10th-percentile confidence of correct predictions. Baselines (98.7 / 95.8) come from the old 386-class split, so the Gen 1–3 comparison is approximate.

On FAIL: stop, report the numbers and the worst/thin classes to the user; no export or release.

## Export

`training/export_onnx.py`:

- ConvNeXt output `models/convnext_gen1-9.onnx` (dynamic batch) and `models/convnext_gen1-9_int8.onnx` from `models/best_sketch_v3.pth`; class count read from the class file (no hard-coded 386).
- Existing checks kept: preprocessing parity, ONNX-vs-PyTorch logits, batch-of-3 equals singles.
- **int8 check replaced**: on 500 images drawn from the test split (seeded), int8 top-1 must agree with fp32 top-1 on ≥ 98%.
- ResNet-18 export unchanged (`resnet18_gen1.onnx`).
- Copies `models/best_sketch_v3_classes.txt` to `models/best_sketch_classes.txt` (the file the inference service and web app read).

## App changes

**Inference (Flask)**

- Loads `convnext_gen1-9.onnx` (file name constant in `create_app`).
- `routing.route` returns `"gen1-9"` for the main model; `"legacy-gen1"` and the rule (top-1 in first 151 dex names and specialist ≥ 55%) unchanged.

**Web**

- `Pokedex.GenerationOf`: dex boundaries 151, 251, 386, 493, 649, 721, 809, 905, 1025 → generations 1–9 (0 if unknown).
- Stats "By generation": Gen 1 … Gen 9, always all nine in order.
- Stats "By model" labels: `gen1-9` → "Gen 1–9 model", `gen1-3` → "Gen 1–3 model (previous)", `legacy-gen1` → "Gen 1 specialist". Past rows keep `gen1-3`.
- `result.js` badge: `gen1-9` → "Gen 1–9 model" (keeps `gen1-3`, `legacy-gen1`).
- Copy: Guess page "(Gen 1–3)" → "(Gen 1–9)"; Live page download note sizes from the new files.
- Live: `MODEL_VERSION = "v3"`; model URLs `convnext_gen1-9.onnx` / `convnext_gen1-9_int8.onnx`; download labels show the new sizes. Search threshold stays 80% unless the gate's confidence check shows a drop, in which case the user picks a new value.
- `best_sketch_classes.txt`, `class_names_v2.txt`, `pokeapi_slugs.json` are the regenerated files (already linked into the web app's `Data/`).

**Deploy**

- One-time: release **`models-v3`** with `convnext_gen1-9.onnx`, `convnext_gen1-9_int8.onnx`, `resnet18_gen1.onnx` (user approval required).
- `deploy.yml`: download `models-v3`; inference gets `convnext_gen1-9.onnx` + `resnet18_gen1.onnx`; web `publish/models/` gets the two ConvNeXt files; verify step checks `/models/convnext_gen1-9.onnx` size.
- Rollback: `models-v2` stays published; reverting the PR redeploys the Gen 1–3 model.
- README: title, class count, image count, results table, Live/model names.

## Testing

- **Python:** `safe_name` cases (`Type: Null`, `Mime Jr.`, illegal characters, double spaces, already-safe names unchanged); class-list validation rejects a changed #1–386 name, a duplicate, an unsafe name, a > 40-char name, a missing slug; routing returns `gen1-9`; existing inference tests stay green.
- **.NET:** `GenerationOf` for Turtwig (#387 → 4), Arceus (#493 → 4), Victini (#494 → 5), Pecharunt (#1025 → 9) plus existing Gen 1–3 cases; Stats `ByGeneration` has 9 entries; By-model labels for `gen1-9`, `gen1-3`, `legacy-gen1` on the Stats page.
- **Gate:** as above.
- **Manual (local, then production):** Upload Gen 4–9 artwork (Lucario, Greninja, Sprigatito) → correct with "Gen 1–9 model"; a Gen 1 image → "Gen 1 specialist"; Live with the canvas feed downloads the v3 model and recognizes a Gen 4–9 Pokémon; Stats shows the new labels and Gen 4–9 rows.
